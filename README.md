# supplementary data tables

# lineage_DRP_Gentgate25.csv
this spreadsheet contains all phenotypic preculture and coculture data from 133 erythromycin-gentamicin clinical isolate cocultures in COGTRA, as outlined in the main text

# DRP_ET.csv
this spreadhseet contains all phenotypic preculture and coculture data from 60 erythromycin-tetracycline clinical isolate cocultures in COGTRA as outlined in the main text

# genomics_mastersheet_filtered.csv
this spreadsheet contains metadata provided for the macotra collection such as country of isolation, site of infecetion. Following this metadata, the following genomics tools have been summarised:
-> MLST 
-> QUAST assembly quality assessment
-> NCBI AMRFinderPlus
-> plasmidfinder rep type (Abricate)
-> custom hsdS (type I RM) BLAST
-> custom integrase (phage) BLAST
-> custom tra gene (conjugation) BLAST
-> DefenseFinder 

# plasmid_inventory_annotated.tsv
this spreadsheet contains the putative plasmid gene hits in the MACOTRA collection using MOB-suite, including 
-> size of each hit
-> GC content
-> rep type
-> relaxase type 
-> mpf type 
-> oriT type
-> nearest MASH neighbour (+ accession)
